Gamify the learning experience of students like never before. Unlock achievements, earn rewards, and make education a captivating journey.

**Requires**

1. [Masteriyo LMS](https://masteriyo.com/pricing/)
2. [GamiPress Plugin](https://wordpress.org/plugins/gamipress/)
3. [GamiPress Integration Add-on](/getting-started/activate-masteriyo-addons)

## Setup and Configuration

### Configuring GamiPress Plugin

To integrate the GamiPress features for your site's students, you will have to install and activate the GamiPress plugin at first and configure the following options.

1. **Points**
2. **Achievements**
3. **Ranks**

[Click here to learn more about creating these options](https://gamipress.com/docs/tutorials/)

### Integrating the GamiPress Options to the Masteriyo Student's Experiences

Once you have configured the required options in the GamiPress plugin, go to the following location.

        Masteriyo > Settings > GamiPress

![gamipress-settings](https://img.masteriyo.com/w:auto/h:auto/q:auto/id:9e238e69b91697cd7cba4af89c459f71/directUpload/Gamipress-settings.png)

Here, you will find the following options to set up. 

#### Points

From here, you can configure the location for showing the points created with GamiPress add-on with the Masteriyo. 

![gamipress-points](https://img.masteriyo.com/w:auto/h:auto/q:auto/id:ad994c56395de2b79f7292d1983f0162/directUpload/gamipress-points.png)

- **Show Types** - Select the points type from the list of the available point types created with GamiPress. You can select **All** or individual or random. 
- **Page** - Choose **Account Page** to place these points. (As of 3.5.0, the **Learn Page** option and its location choices were removed — see the callout below.)
- **Location** - Select where on the Account Page the points should appear.
  ![points-location-for-account-page](https://github.com/Masteriyo/masteriyo-docs/assets/75772539/90bcf157-c240-45a7-b573-d6704288ad21)

  Here is an example when the location is selected as **Dashboard Card**

  ![points-on-account-page-dashboard](https://img.masteriyo.com/w:auto/h:auto/q:auto/id:e6568ef72289da26b615655929cde9f5/directUpload/gamipress-account-dashboard.png)

  **Note:** If you select the **New Tab** option, you can set a custom tab name.

<Callout>
  **Since 3.5.0:** Points, ranks, and achievements on the learn page are no
  longer placed manually. The redesigned [learn
  page](/course-creation/learn-page-experience) shows them automatically
  in a rewards pill in its header, so the five Learn Page placement options
  (and their location pickers) are gone — only **Account Page** placement is
  configurable now.
</Callout>

### Achievements and Ranks

Similarly, you can set the **Achievements** and **Ranks** exactly the same way you do for the **Points**.
