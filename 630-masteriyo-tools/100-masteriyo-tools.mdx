The Tools section in the Masteriyo plugin helps you import/export courses and add sample courses to your site with ease.

        Masteriyo > Tools

## Courses Import/Export

![import-export-course](https://github.com/Masteriyo/masteriyo-docs/assets/75772539/a31f51aa-ea86-4eb8-b5dc-fad8247e4586)

You can import or export courses from here. You will need the courses to be in JSON format for importing.

You can upload the JSON file using the upload button and click on the Import Courses button. The courses will thus be imported and will be available at **Masteriyo > Courses**.
Similarly, just click on the Export Courses button and you can download the available courses in a JSON file.

### Quizzes Import/Export

![quizzes-import-export](https://github.com/Masteriyo/masteriyo-docs/assets/75772539/d2be1cac-16c7-4df5-9a09-c35366c0cf95)

You can now import or export the quizzes you have created with the Masteriyo LMS. You can also import individual quizzes from the course builder. Here's a [detailed guide on importing or exporting individual quizzes](/faqs/import-and-export-individual-quizzes).

## Sample Courses

![sample-course](https://github.com/Masteriyo/masteriyo-docs/assets/75772539/0e9a15bd-669f-4c76-83fa-72cb91f65f33)

Using this feature, you can install sample courses created by our team into your site. This will help you understand how to create a course in an elegant manner. Choose whether you want the courses to be published directly or saved as drafts, then click the Install button.

Once the installation is completed, you can find the installed courses at Masteriyo > Courses

![installed-courses](https://github.com/Masteriyo/masteriyo-docs/assets/75772539/78abc061-c682-403b-8045-2dd6d5679364)

## Users Import/Export

![import-export-users](https://github.com/Masteriyo/masteriyo-docs/assets/75772539/d4e3165e-6c4e-4fda-ae01-0c1b03d47ad5)

You can import/export users from here. This supports CSV files only.

## Utilities Tab

![utilities-tab](https://github.com/Masteriyo/masteriyo-docs/assets/75772539/95d50531-b9aa-44d4-b6ba-1a1e3dcee92e)

Improve your course access by removing cache. This ensures the courses are up to date and error-free.
