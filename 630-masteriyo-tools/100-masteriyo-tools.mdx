The Tools section in the Masteriyo plugin helps you import/export your whole site or individual courses, and add sample courses to your site with ease.

        Masteriyo > Tools

## Full Site Import/Export (v3.5+)

A **Full Site** tab on the Import/Export screen lets administrators move Masteriyo content between sites — for example, cloning a staging setup to production, or migrating to a new host — without reconfiguring everything by hand. This tab is visible to administrators only.

**Exporting:**

1. Choose which parts to include: **Settings**, **Users**, and/or **Courses** (all three are selected by default).
2. Click **Export**. The export runs in the background — courses can take a while on larger sites — and the screen polls for progress until it's ready.
3. Download the generated **.zip** file once the export completes.

**Importing:**

1. On the destination site's **Full Site** tab, choose the **.zip** file produced by an export.
2. Click **Import**. The file uploads in chunks, so large exports aren't blocked by your host's upload-size limit.
3. Masteriyo imports each included section and reports its own result — if settings or users import fine but something in courses fails, you'll see a per-section status with a message instead of one all-or-nothing result.

![Full Site Import/Export tab](https://img.masteriyo.com/w:auto/h:auto/q:auto/id:27a03ec55d11fe026694613cda0b20ab/directUpload/full-import-export.png)

<Callout>
  Full-site export/import is separate from the **Courses**, **Users**, and
  **Settings** tabs below — those import/export one type at a time in JSON or
  CSV, while Full Site bundles everything into a single transferable .zip.
</Callout>

## Courses, Users, Settings & Quizzes Import/Export

The **Courses**, **Users**, **Settings**, and **Quizzes** tabs all work the same way: choose a file and click **Import**, or click **Export** to download your current data. What differs between them is the file format and what gets moved:

- **Courses** — **.json** file. Imported courses appear at **Masteriyo > Courses**.
- **Users** — **.csv** file only.
- **Settings** — **.json** file, covering your Masteriyo settings.
- **Quizzes** — **.json** file. You can also import or export individual quizzes directly from the Course Builder — see the [detailed guide](/faqs/import-and-export-individual-quizzes) for that workflow, including the PDF answer key export.

<Callout>
  Settings and Users are visible to administrators only, matching the Full Site
  tab above.
</Callout>

## Sample Courses

![sample-course](https://img.masteriyo.com/w:auto/h:auto/q:auto/id:b802a0aab4c292d1507c65bc385e5457/directUpload/sample-courses.png)

Using this feature, you can install sample courses created by our team into your site. This will help you understand how to create a course in an elegant manner. Choose whether you want the courses to be published directly or saved as drafts, then click the Install button.

Once the installation is completed, you can find the installed courses at Masteriyo > Courses

## Utilities Tab

![utilities-tab](https://img.masteriyo.com/w:auto/h:auto/q:auto/id:4808d7c206a8a1ca12de35a2e147b744/directUpload/utilities.png)

- **Refresh Course Access** — click **Clear Cache** to remove temporary glitches, like duplicate enrollments, caused by website caching. This keeps your course list up to date and error-free.
- **Force Plugin Update** — click **Check for Update** to manually check whether a newer version of Masteriyo is available. If one is found, an **Update Now** button appears to install it right away. Use this when automatic updates aren't available or you need to update immediately.
