This guide walks you through every step of building a professional WordPress course from initial setup to publication using Masteriyo LMS. From basic course information to advanced features like content dripping and enrollment management, discover how to leverage Masteriyo's full potential for your e-learning success.

## Accessing Course Creation Interface

To access the course creation interface on your WordPress website: 

- Navigate to **Masteriyo** > **Courses** and click **Add New Course**.

![Add New Course](https://raw.githubusercontent.com/Masteriyo/masteriyo-docs/main/assets/images/course-creation/navigate-to-course-and-add-new-course.png)

- A new course builder interface will appear. 

## Basic Course Setup 
Let's now set up the course with the required information:

- In the **Course Name**, enter a suitable name for your course.
- Add a short course description in the **Course Description** editor. You can also style the description and add links and media in the description editor.
- Next, enter the main features of the course in the **Course Highlights** box. You can enter the main highlighted features of the course in bullet points. Course highlights will be shown on the course listing page.
- On the right side of the interface, you can add **Categories**. You can select a category from the dropdown if you already have a category. If not, you can create a new one by clicking on **Add New Category**. 
- Now, add the slug for your course, which is the course URL.
- Click **Add Featured Image** to add an image for the course.

![Masteriyo Course Setting for Free Version](https://raw.githubusercontent.com/Masteriyo/masteriyo-docs/main/assets/images/course-creation/masteriyo-course-setting-for-free-version.png)

<Callout>
  The Course Description editor and lesson content editors can now use
  **different editors** [Pro] — set them independently under **Masteriyo →
  Settings → General → Editor** (Default Editor for lessons, Course Overview
  Editor for the description shown on the single course page).
</Callout>

### Premium Features on Course Builder [Pro]

If you have Masteriyo Pro, you can set the course as a featured course and add a featured video.

- **Featured:** Enabling the Featured toggle button helps you to highlight the course from all your courses.
- **Featured Video:** Replace the featured image with a video on your course pages.

![Masteriyo Course Setting for Pro Version](https://raw.githubusercontent.com/Masteriyo/masteriyo-docs/main/assets/images/course-creation/masteriyo-course-setting-for-pro-version.png)

## Course Content Creation

Each course can be divided into **Sections**. Sections are a group of **Lessons**, **Quizzes**, **Assignments**, and so on. Grouping them into different sections is an excellent way to make a course easier to navigate and give your students a quick overview.

- Navigate to **Builder** tab and click on **Add New Section** button. 

![add-new-section](https://raw.githubusercontent.com/Masteriyo/masteriyo-docs/main/assets/images/course-creation/add-new-section-for-course.png)

- Give a name to the section in the **Section Name** field and click **Add**.

![section-name](https://raw.githubusercontent.com/Masteriyo/masteriyo-docs/main/assets/images/course-creation/create-a-new-section.png)

### Adding Course Content

Once you add a new section, you'll see the **Add New Content** link, from where you can add Text Lessons, Video Lessons, Live Streams, Quizzes, Google Meet, Zoom Meetings, and Assignments.

![Click on Add New Content](https://raw.githubusercontent.com/Masteriyo/masteriyo-docs/main/assets/images/course-creation/add-new-content-for-section.png)

Now, select the content type based on your preference.   

![Select Content Type](https://raw.githubusercontent.com/Masteriyo/masteriyo-docs/main/assets/images/course-creation/select-content-type.png)

<Callout>
  Use the **Search curriculum** box in the Builder tab to quickly filter
  sections and lessons in courses with a lot of content. Each section also
  gets an **Upload** button that opens your media library in multi-select
  mode — every video file you pick becomes a draft lesson in that section
  automatically (PDF and audio files require a paid plan).
</Callout>

### Bulk Editing Lessons

Turn on bulk-select in the Builder tab to check multiple lessons at once and, from the floating selection bar:

- **Publish** or **switch to Draft** in one action
- **Edit Lesson Options** — bulk toggle **Enable Video Share** and **Enable Right Click** across every selected lesson, plus bulk-edit **content drip release dates** [Pro]
- **Delete** the selected lessons (with a two-step confirmation)

## Course Settings
Navigate to **Settings** tab. Each course you make will have its own individual settings that have the course flow, type: free or pro, and many more features. There are six groups of options to set in the individual settings. They are,

- **Pricing**
- **Group Pricing**
- **General**
- **Schedule & Access** (includes Cohort Mode [Pro] and Enrollment Expiration [Pro])
- **Display**
- **Content Drip**

Active add-ons add further tabs (Certificate, Prerequisites, FAQ, WooCommerce, Lemon Squeezy, Paid Memberships Pro, Restrict Content Pro).

<Callout>
  The Certificate tab's certificate selector now includes a **Create new
  certificate** option directly in the dropdown, so you don't need to leave
  the course builder to set one up.
</Callout>

<Callout>
  From **Masteriyo → Addons**, active add-ons like Zoom or Google Meet now
  show a **Settings** (gear) button that jumps straight to that add-on's
  configuration, instead of hunting for it under Settings.
</Callout>

### Pricing
From this tab, you can set the course's price. You can either make the course Free or charge for it.

![Free Pricing Option](https://raw.githubusercontent.com/Masteriyo/masteriyo-docs/main/assets/images/course-creation/free-pricing-option.png)

#### Free 
If you decide to make the course free, you will then have two additional options: 
 - You can either allow the students to enroll in your course without registering  
 - Or make the registration compulsory.

#### Paid
For paid pricing as well, you've two options:  
- **One Time** 

  Set a one-time fee for the course you have created. 

![Pricing for Paid](https://raw.githubusercontent.com/Masteriyo/masteriyo-docs/main/assets/images/course-creation/paid-pricing-option.png)

The enrollers must then pay this amount to take the course. You can also add a sale price so that the course will display both the original price and the sale price. 

- **Recurring** [Pro]  

  Recurring creates a subscription-based course where students pay repeatedly at set intervals to maintain access. 

![Recurring Pricing Option](https://raw.githubusercontent.com/Masteriyo/masteriyo-docs/main/assets/images/course-creation/recurring-pricing-option.png) 

You can set a **Subscription Price** (how much they pay each billing cycle) and choose the billing frequency (every week, month, or year). The **Expire After** setting determines when their access ends if they don't renew. 

### Group Pricing

This tab lets you set up quantity-based pricing tiers so a buyer can purchase multiple seats of the course at once, typically at a discounted per-seat rate. See [Groups](/free-addons/group-course) for the full walkthrough — pricing tiers, fixed vs. variable seats, and managing group enrollments.

### General
In this tab, you will find basic course related settings like instructor, difficulty, duration, etc. All these settings are explained briefly as below: 

![General Course Setting for Free Version](https://raw.githubusercontent.com/Masteriyo/masteriyo-docs/main/assets/images/course-creation/general-course-setting.png)

#### Course Basics

- **Instructor** - Search and select the course's instructor from your site's admins and instructors. The user who created the course is selected by default.
- **Additional Instructors** [Pro] - Add more than one instructor if the course is prepared by a group of instructors.
- **Difficulty** - Choose the course level from a dropdown (e.g. Expert, Intermediate, Beginner) as per the course's contents.
- **Duration** - Set the course duration in hours and minutes.
- **Course Badge** - Give a badge to your course, such as "Expert's Choice", and so on.

#### Access & Restrictions

- **Maximum Students** - Choose **No limit**, or **Limit** and enter the maximum **Number of Students** allowed to enroll.
- **Static Enrolled Count** - Add a base number of students that is added to the actual enrollment count displayed on the course. Only available when Maximum Students is set to no limit.
- **Password** - Set a password for the course. The students will have to enter the password to view/enroll. Click the eye icon to reveal what you typed.
- **Allow Course Retake** - Enable this option to allow users to retake the course.
- **Restrict Content During Quiz** - Enable this option to restrict the course content when a student is doing the Quiz.
- **Assignment options** [Pro] - When the Assignment add-on is active, extra assignment-completion and retake controls appear here as well.

### Schedule & Access [Pro]

This tab controls when and how students can access the course.

- **Cohort Mode** [Pro] - Group enrolled students into cohorts that move through the course together on a shared schedule.
- **Course Coming Soon** - Show the course but block enrollment until the date you specify.
- **End Date** - Set a date for when the course ends. Once the date has arrived and passed, the course will then change into Draft.
- **Enrollment Expiration** - From here, you can set a deadline for students to complete your course after they enroll. Once enabled, you can specify a time limit in days, and students must finish the course within that timeframe or lose access.

![Enrollment Setting](https://raw.githubusercontent.com/Masteriyo/masteriyo-docs/main/assets/images/course-creation/enrollment-setting-on-masteriyo-pro.png)

### Display

- **Welcome Message For User** - Displays a personalized greeting when students first access your course learning page. Add a custom welcome title and description to provide important course information or instructions.

You can also preview the welcome message:

![Preview welcome message](https://raw.githubusercontent.com/Masteriyo/masteriyo-docs/main/assets/images/course-creation/preview-welcome-message.gif)

Curriculum visibility, reviews, and course layout are no longer per-course settings here — they now apply **globally to every course**, and this tab links you to where to change them instead of duplicating the controls:

- **Masteriyo → Settings → Styles**
- **Masteriyo → Settings → Single Course Page → Display**

See [Single Course Settings](/settings/single-course-page) for the full list of these options.

### Content Drip
Content Drip controls when course lessons become available to students after enrollment. Instead of releasing all content at once, you can: 
- **Free**: All lessons are  available immediately.  
- **Sequential**: Next lesson unlocks only after completing the previous one.  
- **Date Selection** [Pro]: Release lessons on specific dates you choose.  
- **X Days From Enrollment** [Pro]: Lessons unlock automatically after a set number of days from when each student enrolls. 
 
![Select Flow Type for Content Drip](https://raw.githubusercontent.com/Masteriyo/masteriyo-docs/main/assets/images/course-creation/select-flow-type-for-content-drip.png)

Once you have set up the course's settings per your requirement, hit the **Publish** button to save the changes. You can also click on the **Preview** button beside the Publish button to glance at the course you have made and see how it appears to the students.   

![Preview Course at Frontend](https://raw.githubusercontent.com/Masteriyo/masteriyo-docs/main/assets/images/course-creation/frontend-view-of-course.gif)
