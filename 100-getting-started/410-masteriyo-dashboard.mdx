Once you install and activate the Masteriyo LMS plugin, you will be able to access the Masteriyo Dashboard. Masteriyo Dashboard is a place from where you can get access to various parts of the plugin like add-ons, settings, documentation, and support. Let us check what this section really consists of.

<Callout>
  {" "}
  Location: Masteriyo &gt; Dashboard
</Callout>

![masteriyo-dashboard](https://github.com/Masteriyo/masteriyo-docs/assets/75772539/cd000f59-5285-4d8e-906c-974927b3396f)

<Callout>
  Clicking the top-level **Masteriyo** item in the WordPress admin sidebar
  takes you straight to the **Courses** list, not this Dashboard page.
  To reach the Dashboard tabs described below, use **Masteriyo → Dashboard**
  specifically.
</Callout>

As you can see, there are various tabs on the dashboard page, in this order: **Home, Analytics, Settings, Addons, Starter Templates, Tools, Free vs Pro (or License), Help, About**. These tabs are described as below:

## Home

From here, you can access Masteriyo video tutorials, community, documentation, etc. Also, if you have any trouble with the plugin, you can directly create a support ticket from here. Moreover, if you see any features missing, you can request the feature as well.
Don't forget to leave a review for the plugin from the **Submit a Review** option.

{/* IMAGE: masteriyo-dashboard-home-tab */}

## Analytics

This is the tab you land on first when opening **Masteriyo → Dashboard**, giving you an at-a-glance view of how your site is doing. For the full walkthrough, see [Analytics Dashboard](/getting-started/analytics-dashboard).

## Settings

The next tab is **Settings**. Click on this tab and you will be redirected to the Masteriyo settings page, from where you can set up the plugin as per your requirements.

        [Wanna learn more about Settings](/settings)

## Addons

In this section, you will find all the free and premium add-ons of the Masteriyo plugin.

![dashboard-addons](https://github.com/Masteriyo/masteriyo-docs/assets/75772539/4746a9d6-98fb-43a1-99b3-b1bfea4063ac)

If you haven't subscribed to a premium plan, you can make a purchase via this page as well. The list comes with advanced sorting and searching options to make your experience better and faster. Also, you can check the active and inactive add-ons from this same spot.

## Starter Templates

In this section, you can browse and import ready-made course templates to quickly get started.

## Tools

This tab provides utilities for managing plugin data, such as import/export and other maintenance tools, and includes the **Status** page.

### Status

Under **Tools → Status**, Masteriyo shows two side-by-side info cards:

- **WordPress** — home/site URL, WordPress version, Masteriyo version, multisite status, memory limit, debug mode, cron, language, and object cache
- **Server** — server software, MySQL version, PHP version, timezone, post max size, execution time limit, loaded extensions, and cURL version

A **Copy Report** button generates a text summary of this information, handy to paste when contacting support.

## Free vs Pro

<Callout>
  This tab only appears if you don't have an active Masteriyo Pro license. If
  your license is active, a **License** tab appears in its place instead,
  showing your license status and activation details.
</Callout>

![dashboard-free-vs-pro](https://github.com/Masteriyo/masteriyo-docs/assets/75772539/fbe94124-247b-4f2b-a56d-ba189314e79b)

In this section, we have compared the free and pro version of the plugin based on the features they have. This way it will be easier for our users to decide whether they need the upgrade or not.

Also, scroll to the bottom of the page and click on the **Get Masteriyo Pro Now** button for upgrading to the premium version of the plugin.

## Help

![dashboard-help](https://github.com/Masteriyo/masteriyo-docs/assets/75772539/7138858a-3e50-4bf3-8f21-f8a7a28605b9)

This tab consists of information required to help the users adapt to the Masteriyo plugins. You can check all the available shortcodes and smart tags from here as well as create a support ticket and view documentation.

<Callout>
  The Help tab is hidden entirely on white-labeled installs.
</Callout>

## About

This tab gives you quick access to Masteriyo resources — a welcome video, shortcuts to add or view courses, and links to the community, documentation, support tickets, feature requests, reviews, and video tutorials (similar to the Home tab).

## Extra options in the Navigation Bar

![dashboard-nav-bar](https://github.com/Masteriyo/masteriyo-docs/assets/75772539/f71e2694-6f33-4fa7-91e2-77cf5587b543)

On the right-hand side of the navigation bar, you will see the version number, an option to upgrade to Pro (hidden once you have an active license), and a bell icon with the latest updates/changelog from our side.

## Commerce Menus on Non-Selling Sites

<Callout>
  If Masteriyo detects your site isn't selling courses (no paid courses set
  up), it automatically hides the **Orders**, **Coupons**, **Subscriptions**,
  and **Withdraws** submenus from the WordPress admin sidebar to keep things
  simple. These reappear automatically once you start selling. Existing sites
  that already use these menus keep seeing them regardless.
</Callout>
