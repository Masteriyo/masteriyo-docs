Read these in order the first time. Start with **System Requirements**, install the plugin, then activate the
add-ons you need — most capabilities in Masteriyo are add-ons you switch on, so a feature you cannot find is often
just an add-on that is off. Once the plugin is running, go to
[Complete Course Creation](/course-creation/complete-course-creation) to publish your first course.
