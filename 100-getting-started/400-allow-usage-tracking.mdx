## Contribute to Enhancement

![usage tracking](https://user-images.githubusercontent.com/75772539/237024495-24ab8eda-e801-4b67-ab3a-af07db99ef51.png)

![contribute](https://user-images.githubusercontent.com/75772539/237024736-2215f924-678e-42a5-8c0b-1ae496dc944b.png)

You will find a notice from the Masteriyo plugin asking for your consent to allow usage tracking. This helps us improve the plugin's features and deliver a better user experience overall.

### What is shared when you enable it

| Field | What it contains |
| --- | --- |
| `admin_email` | The site administrator's email address |
| `base_product` / `product_data` | Which Masteriyo edition and version is installed |
| `plugin_activation_date` / `masteriyo_install_days` | When Masteriyo was first activated, and how long ago that was |
| `wp_version` · `php_version` · `mysql_version` | WordPress, PHP and MySQL versions |
| `locale` · `timezone` | Your site's language/region and time zone |
| `is_multisite` | Whether the site is part of a WordPress multisite network |
| `active_theme` | Name of the active theme |
| `other_plugins` | The number of other active plugins and their names |
| `addons` | Which Masteriyo add-ons are active |
| `publish_course_count` | How many courses you have published |
| `enrolled_users_count` | How many enrollments exist in total |
| `onboarding_data` | Setup-wizard progress: which steps you completed or skipped, the step numbers, and two choices from the welcome step — whether you plan to sell or enroll students, and which payment method you selected. Values are limited to true/false, whole numbers and a fixed set of options; nothing you typed into the wizard is included. |
| `last_error_report` | The most recent Masteriyo error report — see below |

### What is sent even when usage tracking is off

If Masteriyo has recorded an error report, that report is transmitted whether or not you enable usage tracking. It
contains the page URL, error code and message, stack trace, HTTP method, request data, user agent, the time the
error occurred, and Masteriyo's own debug context. Stack traces and request data can include file paths from your
server and the contents of the request that failed.

<Callout>
  If you do not want error reports leaving your site, keep an eye on the plugin's error reporting behaviour and
  raise it with support — the usage-tracking checkbox does not control it.
</Callout>

### How the data is used

The information above is used for improving Masteriyo and for compatibility testing — making sure the plugin works
across PHP versions, themes and other plugins. It is not sold, and it is not shared for advertising.

Enabling the option in the setup wizard also subscribes the administrator email to occasional product emails about
new features and security updates. That is a separate thing from the diagnostic data above, and you can
unsubscribe from those emails at any time.
