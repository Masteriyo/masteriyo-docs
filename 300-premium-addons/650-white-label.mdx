The White Label add-on allows you to rebrand Masteriyo with your own brand name, logo, menu icons, and user role names. This helps you provide a branded experience in the WordPress dashboard without displaying the default Masteriyo branding.

## Prerequisites

Before configuring White Label, make sure you have:

1. An active [Masteriyo LMS Elite plan](https://masteriyo.com/pricing/).
2. The [White Label Add-on activated](/getting-started/activate-masteriyo-addons).

## Activate the White Label Add-on

1. Go to your WordPress dashboard and navigate to **Masteriyo > Addons**.
2. Search for **White Label**.
3. Once found, toggle the switch to enable the white label addon.

![enabling-white-label-in-masteriyo](https://mlcucdwjz8hi.i.optimole.com/w:auto/h:auto/q:auto/id:910f1a3c02ff6a27c870270084eba8e1/directUpload/enable-white-label-addon.png)

## Configuration

1. Go to your WordPress dashboard and navigate to **Masteriyo > Settings > Advanced**.
2. Click on **White Label**.
3. Configure your brand name, logo, and menu icons using the available fields (see below).
4. Click on **Save Settings**.

![masteriyo-white-label-settings](https://mlcucdwjz8hi.i.optimole.com/w:auto/h:auto/q:auto/id:7c650f48d016019ab9c80e59c0193fbe/directUpload/masteriyo-white-label-settings.png)

The available fields are described below:

- **Title**: Replaces "Masteriyo" with your own brand name across the WordPress dashboard, including the admin menu label.
- **Active Menu Icon**: The icon shown in the WordPress admin sidebar when the Masteriyo menu is active/selected.
- **Inactive Menu Icon**: The icon shown in the WordPress admin sidebar when the Masteriyo menu is not selected.
- **Logo**: Your brand logo, shown in place of the Masteriyo logo within the plugin's dashboard and pages.
- **Student Role Name**: Replaces the default "Masteriyo Student" user role label with your own custom name.
- **Instructor Role Name**: Replaces the default "Masteriyo Instructor" user role label with your own custom name.

<Callout>
  After saving the settings, reload the page for the changes to take effect.
</Callout>
