The order summary shortcode is:  `[masteriyo_order_summary]` \
This shortcode renders the order (thank-you) summary for the order that was just completed. It reads the order ID and key from the post-checkout URL, so it should be placed on the page students land on after a successful checkout.

This shortcode has no attributes — just add the tag to your page:

```
[masteriyo_order_summary]
```

## Where to Use It
Create a custom "Thank You" page and add the `[masteriyo_order_summary]` shortcode to its content. After a student completes checkout, the page displays a summary of their order.

<Callout>
Masteriyo also provides a **Post-Checkout Landing Page** option under **Masteriyo > Settings > General > Pages**, which lets you redirect users to a specific page after checkout. Point it at your custom thank-you page so the order summary is shown right after a successful order.
</Callout>
