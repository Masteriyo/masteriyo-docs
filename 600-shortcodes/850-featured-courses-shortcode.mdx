### Featured Courses Shortcode [Pro]

Using the shortcode for featured courses, you can display your Featured courses anywhere on your site. It shows only the courses you have marked as **Featured** in the course editor.

The default shortcode is: `[masteriyo_featured_courses]`

<Callout>
This is a Pro feature. The `[masteriyo_featured_courses]` shortcode is available only in Masteriyo Pro.
</Callout>

### Attributes

The shortcode supports the following attributes for customization:

| **Attribute** | **Default** | **Description** |
|----------------|-------------|-----------------|
| `max` | 6 | Maximum number of featured courses to display. |
| `columns` | 3 | Number of columns used to arrange the courses in the grid. |

### Example

You can use the shortcode to display featured courses with a specific configuration. For example:

```
[masteriyo_featured_courses max="8" columns="4"]
```

This shortcode always pulls courses marked as Featured, so there is no category attribute to configure.
