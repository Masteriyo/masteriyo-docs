---
title: How to add a student manually to a course?
show_child_cards: true
excerpt: Manually enroll a student in a Masteriyo course by creating a completed order — no checkout needed; works for both free and paid courses.
---

Basically, you need to create **an order** to provide access to any course to a student.<br />
So, please follow the steps below to do so.

1. Please login to your site's WordPress dashboard.
2. Go to **Masteriyo > Orders**.
3. Click on **Create New Order** button.
4. For the **Status** dropdown option, please select the **Completed** option.
5. For the **Customer** option, please find the student that you want to provide the course to and select that student.
6. For the **Course** option, please find the course that you want the student to have access to and select that course.
7. Click on the **Create Order** button and that's it.

Now, once the student logs in to their account and visits the course page for which access was provided, they will be able to enroll in the course.
