title: How to update a plugin manually?
show_child_cards: true
excerpt: Manually update the Masteriyo Pro plugin (or any WordPress plugin) by uploading the latest zip via Plugins > Add New > Upload Plugin.
---

Sometimes a plugin needs to be updated manually — for example, when an automatic update is not available. Follow the steps below to update any plugin on your site:

![installing-plugin-masteriyo](https://user-images.githubusercontent.com/24367265/189650984-03bde100-df15-41e1-b7dd-1eabc12258b1.png)

1. Download the latest version of **Masteriyo Pro** zip file from the email you received during the purchase.
2. Go to your **Dashboard** -> **Plugins** -> **Add New**
3. Click on the **Upload Plugin**
4. Choose the zip file you downloaded earlier
5. Click on **Install Now**
6. Click on **Replace current with uploaded** to replace the old version plugin
