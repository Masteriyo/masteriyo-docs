---
title: How to enable light/dark mode in Learn pages?
excerpt: Learn how to enable light or dark mode on the Masteriyo learn page using the theme toggle in the top navigation bar.
---
Follow the steps below to enable light/dark mode in Learn pages. 

1. Go to the Courses page.
2. Click on Start Course.
3. In the top navigation bar, you will see the option to enable light or dark mode.
